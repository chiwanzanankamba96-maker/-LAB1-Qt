# Лабораторная работа № 1 — Qt (C++)

## Описание проекта

Приложение разработано на языке C++ с использованием фреймворка Qt и базы данных SQLite.

Программа позволяет создавать графические фигуры, управлять ими и сохранять информацию в базе данных.

## Основные возможности

- Создание прямоугольников, эллипсов и многоугольников.
- Перемещение фигур с помощью мыши.
- Соединение фигур динамическими линиями.
- Сохранение фигур и связей в SQLite.
- Отображение данных через QSqlTableModel и QTableView.
- Фильтрация по идентификатору, типу и количеству фигур.
- Удаление фигур и связанных с ними линий.
- Отображение количества фигур с помощью графических значков.
- Восстановление расположения фигур после перезапуска приложения.

## Используемые технологии

- C++
- Qt 6 (Qt Widgets, Qt SQL)
- SQLite
- CMake

## Запуск проекта

1. Открыть `CMakeLists.txt` в Qt Creator.
2. Выбрать комплект сборки Qt 6 с поддержкой Qt Widgets и Qt SQL.
3. Собрать и запустить приложение.

База данных SQLite создаётся приложением при первом запуске.
